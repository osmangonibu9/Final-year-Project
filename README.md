# Cyclone Risk Assessment using GIS-based CVI and AHP

## Overview
This project presents a GIS-based framework for assessing cyclone risk in coastal Bangladesh by integrating hazard, exposure, vulnerability, and mitigation capacity. The Coastal Vulnerability Index (CVI) and Analytic Hierarchy Process (AHP) were used to identify spatial patterns of risk and support evidence-based disaster management planning.

## Objectives
- Assess cyclone hazard, exposure, and vulnerability across the study area
- Integrate mitigation capacity into the overall risk framework
- Identify spatial patterns of high- and low-risk zones using GIS-based multi-criteria analysis

## Methodology
- **Coastal Vulnerability Index (CVI):** used to quantify vulnerability based on physical and socio-economic parameters
- **Analytic Hierarchy Process (AHP):** applied to assign relative weights to risk factors through pairwise comparison
- **GIS-based Multi-Criteria Analysis:** integrated hazard, exposure, vulnerability, and mitigation capacity layers to generate a composite risk map

## Tools & Software
- ArcGIS / QGIS
- Multi-Criteria Decision Analysis (MCDA)

## Data
- Satellite and secondary data on hazard exposure, land use, and socio-economic vulnerability indicators for the study area

## Output
- Spatial risk map highlighting zones of varying cyclone vulnerability
- Insights to support targeted adaptation and disaster mitigation planning
